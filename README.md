# DotGlobe VPN

Premium VPN app for Android with .dgvpn config support.

## Features
- Import `.dgvpn` config files (DotGlobe exclusive format)
- 3D globe with Three.js
- Live speed graph
- iOS-style design with glassmorphism
- Config management (rename, activate, delete)
- VpnService scaffolding

## Build
APK is built automatically via GitHub Actions on every push.

## Download APK
Go to Actions tab → Build APK → download artifact.
